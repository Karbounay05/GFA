# Security Policy

## Reporting a Vulnerability

If you find a security issue in this agricultural project:
- Do not disclose publicly
- Email us directly at [karbounay05@gmail.com]
- Provide steps to reproduce the issue

We will review and fix confirmed vulnerabilities as soon as possible.
